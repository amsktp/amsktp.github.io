프로젝트 1: 비가시성 워터마크 연구

지속 과제 · 1 ~ 2명
프로젝트 개요 (목적/역할)
  • 촬영·캡쳐 환경에서도 높은 검출률을 유지하는 비가시성 워터마크 알고리즘 연구 및 실험 환경 구축
  • 기존 프로토타입 기반 워터마크 알고리즘을 상용 수준으로 재설계
  • 비가시성 향상, 촬영 환경 검출 안정성 개선, 페이로드 복원율 개선
  • 알고리즘 실험 환경 및 멀티 플랫폼 테스트 구조 설계·구현
문제 정의 (Problem)
  • 기존 워터마크는 비가시성과 검출 안정성이 동시에 낮아 상용화에 한계
  • 데스크톱 중심 구조로 모바일·웹 환경 검증이 어려움
  • 팩스, 2Bit, CMYK 등 저비트·특수 포맷에서 삽입 자체가 불안정
접근 방식 (Approach)
  • 워터마크 삽입 및 검출을 공통 엔진 구조로 설계하고 플랫폼별 입출력만 분리
  • 모바일 환경 기반 검출 실험을 위한 파라미터 조정 앱 개발
  • 카메라를 통한 프레임 내 워터마크 검출, 이미지 검출 수행
  • 잉여 워터마크 영역 활용 추가 페이로드 삽입 구조 설계 (144bit x 3)
  • 암막 상자, 고정 조명, 디바이스 위치 고정 장치를 활용한 재현 가능한 실험 환경 구축
구현 내용 (Implementation)
  • 멀티 플랫폼 테스트 프레임워크 구축
    • Desktop: Windows / macOS / Linux (Docker)
    • Mobile: iOS / Android (카메라 프레임 기반 검출)
    • Web: 브라우저 환경 삽입·검출 테스트
  • 주파수 필터 기반 워터마크 성분 추출 및 삽입 강도 조정 로직 개선
  • 디코딩 단계 검출 방식 개선
  • 워터마크 모양, 데이터 삽입 색 채널, 삽입 방식 실험
  • RGB 기반 삽입 한계 분석 후 Lab 색 공간 기반 삽입 방식 전환
    • HVS 특성 고려
    • L/a/b 채널 비교
  • 확대/회전 판단 알고리즘 개선으로 검출 파이프라인 리소스 최적화
  • 팩스 및 2Bit 영상 환경 대응 저비트 영상용 워터마크 삽입 방식 개발
  • 워터마크 인식률 측정 객관 지표 제작 및 지표 저장 DB/백엔드/웹 개발
성과 및 결과 (Result)
  • 동일 조건 테스트 환경에서 기존 대비 검출 성공률 유의미하게 개선
  • Windows 한정 디버깅 환경에서 iOS, Android, Web, Linux, MacOS, Windows 지원으로 확장
  • Android, iOS, Windows 별도 소스 관리 환경에서 단일 소스로 프로젝트 간 차이 제거
  • 불필요한 연산 제거로 검출 알고리즘 리소스 사용량 감소
  • 특허 등록 2건: 팩스/2Bit 영상 워터마크 삽입 방식, 비가시성 강화 영상 워터마크 삽입 방식
    • 2Bit 영상 워터마크 삽입 방식 관련 특허 (출원)
      • https://patents.google.com/patent/KR20250169131A
    • 비가시성 강화 영상 워터마크 삽입 방식 관련 특허 (등록)
      • https://patents.google.com/patent/KR102679321B1
  • 비가시성과 강인성(robustness) Trade-off 기준 반복 실험으로 삽입 강도 및 패턴 구조 최적화
  • 비가시성 워터마크 기술이 사내 주력 솔루션(LabGuard) 핵심 기술로 확장
내가 기여한 핵심 포인트 (My Contribution)
  • 비가시성 워터마크 알고리즘 코어 로직과 실험 환경 단독 주도
  • 단일 C++ 코어 엔진 유지를 위해 JNI/Objective-C++ 브릿지 구성, 플랫폼 종속 로직과 알고리즘 코어 분리
  • 비가시성 워터마크 삽입 및 검출 알고리즘 설계
  • 멀티 플랫폼 테스트 구조 초기 설계 및 구현
  • 모바일 카메라 기반 검증 환경 직접 개발
  • 특수 포맷(팩스, 2Bit 영상) 대응 워터마크 방식 연구 및 구현

  • Platform: Windows, macOS, Linux, iOS, Android, Web

프로젝트 2: 비가시성 워터마크의 확장

지속 과제 · 1 ~ 2명
프로젝트 개요 (목적/역할)
  • 비가시성 워터마크 기술을 활용하여 다양한 멀티미디어에 적용
  • 플랫폼 별 이미지, 비디오, PDF 등 다양한 멀티미디어 워터마크 적용 검토
문제 정의 (Problem)
  • 이미지뿐 아니라 동영상, PDF 등 다양한 대상물에 워터마크 적용 니즈 확인
  • 이미지의 DPI, Color Profile 등 다양한 옵션 적용 필요
접근 방식 (Approach)
  • 고객사 니즈에 따라 다양한 대상물에 비가시성 워터마크 삽입/검출 개발
구현 내용 (Implementation)
  • 동영상
    • FFMPEG 디코딩→프레임 삽입→재인코딩 방식 검토
    • FFMPEG CLI Filter 기반 비가시성 워터마크 삽입/검출 채택
    • 코덱 다양성, 메타데이터 보존 고려
  • 이미지
    • magick++로 CMYK 채널 지원
    • DPI/프로파일 옵션 적용
  • PDF
    • 레스터화 방식 실험 (제거 난이도↑, 용량 증가/품질 저하 발생)
    • 레이어 기반 삽입으로 전환 (용량 증가 최소화, 편집 제한 정책 보완)
  • 화면(Windows): MFC를 이용해 화면에 워터마크 삽입
  • 출력물(Windows): DLL Injection으로 프린트 함수 후킹 후 인쇄 시 워터마크 삽입
  • 팩스: 2Bit 이미지 워터마크 삽입
성과 및 결과 (Result)
  • 사내 주력 사업인 랩가드 솔루션으로 발전
  • 사내 포토카드 사업으로 발전
내가 기여한 핵심 포인트 (My Contribution)
  • 각 멀티미디어 워터마크 삽입 검토
  • 기능 별 라이브러리화를 진행하여 배포 및 재사용 가능하도록 개발
기술적 고민과 의사결정 사례
  • PDF 레스터화 미채택 이유
    • 보안도 중요하지만 우선 사용성 문제가 없어야 함
    • 용량 증가 억제를 우선 판단
  • FFMPEG CLI Filter 선택 이유
    • 디코딩→인코딩 전체 처리 시 코덱 다양성 처리 부담 존재
    • 메타데이터 보존/처리 부담이 커 Filter 전략 채택
기술 스택

  • Video
    • Android(OpenGL)
    • iOS( TODO )
    • Web(ffmpeg)
    • Desktop(ffmpeg)
  • Image
    • Desktop(magick++)
  • PDF
    • Desktop(podofo, mupdf)
  • 화면: MFC
  • 출력물: MFC
  • 팩스: Desktop(Magick++)
